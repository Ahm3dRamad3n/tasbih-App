# 📿 Tasbih App - Digital Rosary (PWA)

A lightweight, fast, and installable **Progressive Web App (PWA)** designed for digital Tasbih (counting Zikr). Built entirely with core web technologies, ensuring maximum performance and offline capabilities.

---

## 🚀 Features
- **PWA Ready:** Fully installable on Android, iOS, and Desktop directly from the browser.
- **Offline Support:** Works seamlessly without an internet connection thanks to Service Workers (`sw.js`).
- **Data Persistence:** Automatically saves your tasbih count using browser LocalStorage (no data lost on exit).
- **Clean UI/UX:** A minimalist, distraction-free interface designed for ease of use.
- **Zero Frameworks:** Built with Pure Logic and Vanilla JavaScript for optimal speed and zero bloatware.
